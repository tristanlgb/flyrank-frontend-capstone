# FlyRank Frontend Capstone

A frontend capstone project for the FlyRank Frontend AI Engineering track. The project will demonstrate an accessible, responsive React interface and a practical AI-assisted development workflow.

## Status

Environment and repository setup are complete. Product development will begin in the next phase.

## Planned stack

- React and TypeScript
- Vite
- CSS Modules
- Vitest and Testing Library
- ESLint and Prettier

The detailed coding and Git conventions are documented in [CLAUDE.md](CLAUDE.md).

## Prerequisites

- Node.js LTS
- Git
- An editor such as VS Code or Cursor
- Claude Code or another course-approved AI coding assistant

## Getting started

The application scaffold will be added in a later assignment. Once it is available, the expected local workflow will be:

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```

## Development workflow

1. Create a focused branch for the task.
2. Use the AI assistant to plan or review the change.
3. Run linting, type checks, tests, and the production build.
4. Commit using the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) format.
