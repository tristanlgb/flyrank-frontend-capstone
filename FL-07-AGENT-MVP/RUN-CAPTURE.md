# Raw Run Capture Guide

Record one continuous, unedited video of about two minutes.

1. Open the project in Cursor and show `input/request.json`.
2. Open the terminal in the project folder.
3. Start recording.
4. Run `npm start`.
5. Keep the GitHub connection, claim count, link count, report path, and final PASS visible.
6. Open `output/verification-report.md`.
7. Show the evidence, HTTP 200 checks, and human-review boundary.
8. Stop recording without trimming.

Suggested narration:

> This is my Portfolio Evidence Agent. It reads a structured request, connects to the live GitHub repository, verifies evidence files, checks public links, and writes a report without mid-run editing.
