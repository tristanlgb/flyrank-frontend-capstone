## Portal notes

I selected FE4, an open capstone focused on making an AI-assisted frontend
workflow visible and verifiable. The specification defines a concrete reviewer,
the primary request-to-response flow, supporting screens, public GitHub and HTTP
data sources, the protected server-side AI boundary, success criteria, and a
clear out-of-scope list.

I chose React and Vite because they match my existing TypeScript experience and
the established repository. Vercel Functions provide the small backend boundary
required to validate input and protect optional model credentials.
