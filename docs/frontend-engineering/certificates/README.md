# FE-02 Certificate Evidence

Add the real completion screenshots from Anthropic Academy to this folder using
these filenames:

```text
claude-101.png
claude-code-101.png
building-with-claude-api.png
```

Required status:

- [ ] Claude 101 completed.
- [ ] Claude Code 101 completed.
- [ ] Building with the Claude API started.
- [ ] Building with the Claude API completed before FE-06/final submission.

The screenshot should show the course title, completion state, and account name
or certificate identity where available. Do not upload passwords, session
tokens, private account pages, or unrelated personal information.

The certificate files are intentionally absent until the real courses are
completed. Placeholder images do not count as evidence.
