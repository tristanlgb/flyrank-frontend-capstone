# Week 3 — Identity Kit

## Assignment Overview

**Assignment:** Decide Once: Build Your Identity Kit  
**Track:** General AI Fluency  
**Week:** 3  
**Workload:** 2 hours  
**Phase:** Foundations  

A consistent visual identity helps a portfolio feel intentional, professional, and coherent. The goal of this assignment is to make a small set of design decisions once so that every page, project, and case study can follow the same visual system.

---

## Typography

### Heading Font

**Space Grotesk**

Use Space Grotesk for:

- Page titles
- Section headings
- Project names
- Navigation highlights
- Logo and monogram text

### Body Font

**Inter**

Use Inter for:

- Paragraphs
- Form labels
- Buttons
- Captions
- Navigation text
- General interface content

Both fonts are free and available through Google Fonts.

---

## Color Palette

| Purpose | Color | Hex Code |
|---|---|---|
| Primary | Purple | `#6D5DF6` |
| Text | Near Black | `#0F1115` |
| Background | Near White | `#FAFAFC` |
| Neutral | Light Gray | `#E2E4E7` |
| Optional Accent | Green | `#22C55E` |

### Usage Guidelines

- Use `#6D5DF6` for primary buttons, links, active states, and important highlights.
- Use `#0F1115` for main text and high-contrast interface elements.
- Use `#FAFAFC` as the main page background.
- Use `#E2E4E7` for borders, dividers, muted backgrounds, and subtle interface elements.
- Use `#22C55E` sparingly for success states or small accents.

The palette should remain calm and minimal so that portfolio projects and case studies remain the main visual focus.

---

## Logo and Favicon

The identity uses a simple monogram based on the initials:

# TL

The monogram should use **Space Grotesk Bold**.

Recommended formats:

- A circular logo for the site header, footer, and branded materials.
- A rounded-square favicon for browser tabs and bookmarks.
- A near-black background with purple initials for the favicon.
- A white or near-white background with dark outlines for the main logo.

The logo should remain simple, readable, and recognizable at small sizes.

## Two-Line Style Note

**Fonts:** Space Grotesk for headings and Inter for body text. Use `#6D5DF6` as the primary color, `#0F1115` for text, `#FAFAFC` for the background, and `#E2E4E7` as the neutral color.

**Mood:** Modern, minimal, and professional. The interface should feel calm, clean, and highly readable so that the projects remain the main focus.

---

## Track Thread Notes

I chose a minimal identity focused on readability and consistency rather than visual effects. The palette uses one primary color with neutral tones so that projects and case studies remain the visual focus across the portfolio.

---

## Design Principles

This identity should follow these rules across the portfolio:

1. Use no more than two font families.
2. Keep the main palette limited to three or four core colors.
3. Use the optional green accent only when it communicates meaning.
4. Prioritize readability, spacing, and visual hierarchy.
5. Avoid decorative elements that compete with the project content.
6. Apply the same typography and color system across all pages and case studies.
7. Keep the logo simple enough to work as both a full-size mark and a favicon.

## Final portfolio evolution

This kit records the Week 3 decision and should remain visible as process
evidence. During the final portfolio consolidation, the visual system evolved
to **DM Sans** for interface text, **Playfair Display italic** for selected
editorial emphasis, a cream background, deep green primary color, and a muted
orange accent.

The change was not made to follow a trend. The purple system suited the earlier
technical capstone screen, while the green and cream system better supports the
final combination of technology, communication, and social research. The
original principles still hold: two font families, a restrained palette,
strong contrast, readable spacing, a simple TL monogram, and project content
ahead of decoration. The current production implementation is the source of
truth for the final visual tokens.
