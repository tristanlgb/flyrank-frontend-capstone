# Round Two Prompt

Implement a user settings form in this React and TypeScript project. Inspect `package.json`, `src/App.tsx`, and the existing styles before coding, then plan the files to modify. Use React Hook Form and Zod, strict TypeScript, visible labels, keyboard-accessible controls, inline validation, `aria-live` feedback, trimmed text values, disabled submission state, and no `any`.

Fields: display name, email, theme (`light`, `dark`, `system`), and email notifications. Display name must be 2–50 characters. Email must be valid. Invalid forms must not submit. Repeated clicks must not create duplicate submissions.

Write tests for valid submission, invalid email, short display name, accessible controls, and submission state. Run tests, type checking, and the production build, then fix any errors.
